# Product photography audit — 13 September 2026

The production catalog contains **43 product families, 185 variants (40 active families)**. All 139 gallery image rows initially classified as photographs were visually reviewed, and all image files/records were inventoried. The local catalog is separate: 44 families/184 variants, including a local-only measuring-ruler fixture. Hidden legacy images were checked for dimensions/provenance and retained for rollback; they are not claimed reviewed source replacements.

The image audit is **not fully resolved**. 97 unique photographs remain; **59 fail the 1024 px minimum on at least one edge**. Passing pixel dimensions alone does not certify sharpness, framing, provenance or exact variant identity. Every family still lacks a complete set of 4–6 useful independent views for its individual variants.

## Completed image changes

- Removed 12 photograph associations containing people/hands, 30 proven surrogate material/model/variant images, and 1 byte-identical plywood duplicate. Original files and media records remain hidden for rollback.
- Removed 7 extra local-only generated/category-image associations. Category files remain for their legitimate category use.
- Restored 3 existing authentic supplier originals (Risalni list, Fotokarton family overview and 200 g Kladivo) with their low native resolution explicitly recorded.
- Upgraded 2 exact Mekol Ekspres 500 g photographs from 975 × 731 to untouched native 1600 × 1200 originals. Sources and SHA-256 checksums are in the remediation manifest. Native wide margins remain a framing limitation.
- Corrected the magnetic/vacuum compass and plain/decimal ruler assignments. Classified the mounting-clamp technical drawing and unit-circle chart as diagrams; neither counts as another photo.
- Added visible, specific accessory exclusions to reviewed retained scenes. No product geometry, colour, labels, prices, stock or specifications were changed.
- Separately removed obsolete photo-only description sentences from the four photograph-empty metal families and goldsmith snips. The exact unit statements, product facts and kit contents remain unchanged; Šeleshamer needed no copy edit. Local, production and canonical import copy match.
- Synchronized future import visibility/assignments. Superseded real-photo/framing executable migrations refuse to replay their obsolete plans.

## Verification and scope

- Every initially visible production photograph was inspected via contact sheets, and accepted replacement/restoration originals were inspected at native detail. Native dimensions and hashes were measured from actual bytes, including hosted originals.
- Live verification fetched 248 of 248 visible image/diagram URLs and matched their SHA-256 checksums; no broken assets. The audit result is at `tmp/product-image-audit/live-assets.json`.
- The later five-description cleanup separately verified zero visible photographs, exact expected descriptions, backup rereads, unchanged non-copy catalog/media/variant data and protected metadata/commerce hashes, and zero repeat mutations. Exact before/after text is in data/catalog/empty-photo-description-cleanup-2026-09.json; the original image-only transaction hash guarantees apply to those original transactions.
- Each image-only transaction wrote and reread a rollback snapshot, preserved product/variant/commerce hashes, checked remaining gallery positions/associations, and verified an immediate repeat plan produced zero mutations. Production snapshots are under `tmp/catalog-refinements/image-policy-production-*`.
- The updated gallery, deletion controls and validation were deployed to [the production website](https://www.atehna-test.site) ([deployment](https://atehna-48o7sxv5j-atehnaxs-projects.vercel.app)). The Linux production build and TypeScript validation passed; production `catalog-public` and `catalog-admin` caches were invalidated.
- Desktop and mobile enlarged previews were visually verified after decoding. Automated navigation to the raw original encountered a Vercel Security Checkpoint; its link target and direct original bytes were independently verified (HTTP 200, JPEG, 1600 × 1200 and expected SHA-256).
- All existing authentic low-resolution sources are explicitly unresolved exceptions. No upscaling or added blank canvas was used to claim compliance. No missing viewpoints were invented with AI.

## Implementation verification

Explicit checks confirmed corrected magnetic-compass and both decimal-ruler assignments. The scan reported zero errors.

## Future additions and review

Upload/save validation checks decoded bytes and pixel dimensions; the editor checks crop bounds and exports at source pixel scale. Every addition still needs visual and source review for people/body parts, sharpness, lighting, framing, exact model/variant and included components. Native provenance must rule out external upscaling or added padding; a large supplied canvas cannot prove that by itself. Retain the source URL, original dimensions and checksum, and confirm the actual variant before adding an image.

## Reproduction

Read-only inventory: `node --env-file=.env.development.local --import tsx scripts/audit-catalog-product-images.ts`. Production requires the guarded production database URL and `--production`.

Image-only remediation: `node --import tsx scripts/remediate-catalog-product-images.ts --target local|production` (dry-run). `--apply` writes a verified snapshot before the transaction. Production requires the immutable hosted replacement URLs to pass source checksum verification. Never rerun the historical full catalog import to perform this update.

The local-only Jeklena merilna letvica fixture has no verified source photos after the unrelated category illustration was removed. It is absent from production.
